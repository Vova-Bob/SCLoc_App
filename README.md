# Про проєкт

**SCLocalizationUA** — перший офіційний застосунок української локалізації **Star Citizen**.

Саме він поклав початок розвитку української локалізації гри та зробив її доступною для тисяч гравців.

Сьогодні розвиток екосистеми продовжується у **SCLOC-Verse**, який розширює можливості проєкту та об'єднує всі інструменти української спільноти Star Citizen в одному сучасному застосунку.

# Важливо

Ця програма **не втручається** у файли, пам'ять або мережеву взаємодію гри.

Вона лише встановлює українську локалізацію та допоміжні файли, не впливаючи на геймплей, баланс або будь-які механіки гри.

Проєкт повністю дотримується правил використання Star Citizen і не надає жодних переваг у грі.

# Інструкція

1. Завантажте останню версію **SCLocalizationUA** з розділу Releases.
2. Запустіть інсталятор та встановіть програму.
3. Відкрийте застосунок.
4. Вкажіть папку гри:

```text
StarCitizen\LIVE
```

При наступному запуску цей шлях буде визначено автоматично.

5. Якщо файл **user.cfg** відсутній — увімкніть відповідний прапорець або створіть його вручну за інструкцією:

https://github.com/Vova-Bob/SC_localization_UA

6. Натисніть **«Встановити локалізацію»**.

# Executive Hangar Timer Overlay

Відображає статус Executive Hangar та час до його відкриття або закриття.

## Глобальні гарячі клавіші

| Комбінація | Дія |
|------------|-----|
| `F6` | Показати / приховати Overlay |
| `Shift+F8` | Увімкнути / вимкнути режим кліків крізь вікно |
| `Ctrl+F8` | Тимчасово вимкнути кліки крізь для перетягування |
| `Ctrl+Shift+F7` | Встановити старт циклу = зараз |
| `Shift+F7` | Ввести час вручну |
| `F9` | Синхронізувати |
| `Shift+F9` | Очистити локальний час та синхронізувати |

## Масштаб

- `Ctrl -`
- `Ctrl =`
- `Ctrl 0`

## Прозорість

- `Ctrl+Alt -`
- `Ctrl+Alt =`
- `Ctrl+Alt 0`

## Фази циклу

| Фаза | Тривалість |
|------|-----------:|
| 🔴 RED | 2 години |
| 🟢 GREEN | 1 година |
| ⚫ BLACK | 5 хвилин |

## Синхронізація часу

Час отримується із сервера у форматі JSON.

```json
{
  "cycleStartMs": 1722880000000
}
```
